# Brawl Bloodline — public data

This site only hosts the **public data file** read by the VRChat world *Brawl Bloodline*
(starter ghost brutes, and later bosses, brute of the week and events).

- File: `brawlbloodline/data.txt`
- No game code, no personal data.

Format (one line per entry):

```
BBDATA;1
G;name;level;seed;look;choices
```
